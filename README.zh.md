# Tondi 链

**Tondi** 是一条高吞吐、隐私优先、仅支持 Taproot 的 DAG 区块链，专为客户端智能合约锚定与数字资产清算设计。其底层由 Avato Labs 重构，提供原生支持 RGB 协议的锚定机制，具备超强并发能力和极致的结构隐私，在不牺牲简洁性与可审计性的前提下实现性能突破。

---

## 🧭 项目概述

Tondi 是一条对齐比特币原则的执行层链，以最小状态和无 VM 架构为核心，专注于：

* 高频交易处理
* 基于锚定的智能合约状态验证
* 隐匿资产发行与治理提交
* 与 BTC、Tondi、Solana 的跨链兼容

Tondi 去除所有冗余状态逻辑，以客户端协议最大化可组合性与可验证性。

---

## 🔧 核心特性

| 组件             | 描述                                       |
| -------------- | ---------------------------------------- |
| 🧱 DAG 架构      | 基于 GhostDAG 并优化收敛路径，支持 10,000+ TPS 与快速确认 |
| 🔒 仅支持 Taproot | 所有输出为 P2TR，禁用传统脚本类型与 ScriptPath          |
| ⚡ Schnorr 签名   | 所有签名统一为 Schnorr，并支持批量验证                  |
| 🔑 锚定混淆        | RGB 与合约承诺输出在链上与普通交易完全不可区分                |
| 🧠 Blake3 哈希引擎 | 替代传统哈希算法，实现极致加速与并行支持                     |
| 🚫 无状态设计       | 无链上虚拟机、无全局状态、无脚本执行，所有验证客户端完成             |
| 🛰️ 原生跨链支持     | 架构支持 adaptor signature 形式的原子交换方案         |

---

## 📦 适用场景

* RGB 资产与稳定币清算网络
